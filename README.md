# Loopify Billing

Private single-user billing website for Loopify SMM.

## Features
- Single admin login
- Client management
- Invoice creation and editing
- INR billing
- Line items with quantity and rate
- Pending/Paid status
- Dashboard totals
- Printable invoices / Save as PDF
- Agency settings
- Browser localStorage persistence

## Login
- Email: admin@loopify.in
- Password: Loopify@2026

## Important
This version stores data in the browser's localStorage and uses a frontend login for a single-user internal tool. It is suitable for personal/internal use. Before deploying publicly, change the demo credentials and consider moving authentication and data storage to a backend such as Supabase.

## Deploy
The repository is static and can be published with GitHub Pages.
